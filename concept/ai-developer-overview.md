## What is Genspark Code

Genspark Code is Genspark's autonomous AI coding assistant — you describe what you want in natural language, and it independently handles planning, writing code, testing, and running, ultimately delivering a working app, all without you needing to know how to code.

What you get isn't a code snippet you have to assemble yourself, but a complete product that goes from idea to runnable (and deployable live with one click): describe something like "build a restaurant landing page with a booking feature," and it'll set up the pages, interactions, and any necessary data storage — ready to preview and go live directly.

## How to access

Entry point: `https://www.genspark.ai/code/` (login required; the older address `https://www.genspark.ai/ai_developer/` still works). From the home page's **BUILD SUITE** group, click the **Code** card to enter.

Once inside, you'll see a **starting point** card home page, with the heading asking "What are you building?". First pick a starting point (which determines the type of app you're building), or remix a ready-made template from the template library, then enter the chat workspace to describe the details.

## What it can do

| Starting point (live card title) | Best for | One-click publish/deploy? |
|------|-----------|----------------|
| Simple Website or Web App | Quick prototypes, landing pages, lightweight sites with a built-in database | ✅ Workspace includes a one-click **Publish** tab |
| Full-Stack Websites or App | Complete web apps with backend logic, authentication, and a database | ✅ One-click publish, optimized for Cloudflare Pages deployment |
| Native App Development | Cross-platform mobile apps built with Flutter | View via preview, export the code |
| Existing GitHub Project | Connect your existing GitHub repo and let AI make changes on it | Depends on your project |
| Bring Your Own SSH Server | Let AI work on your own server | Deploy to your server |
| Shopify Development And Manager | Develop Shopify themes / store features | Connect your Shopify store |

**Recommendation**: Not sure which to pick → if you're only building a frontend display/prototype, choose **Simple Website or Web App**; for a complete app needing a backend, login, and database, choose **Full-Stack Websites or App** (its card notes it's optimized for Cloudflare Pages deployment). Both web starting points' workspaces include a one-click publish entry.

## How credits are calculated

Generating and editing code consumes credits (billed by usage); actions like running previews, browsing/downloading code, deploying, and connecting GitHub don't incur extra charges themselves. Describing your needs clearly and reducing back-and-forth rework is the most effective way to save credits.

## FAQ

**I can't code — can I still use it?**
Yes. Genspark Code is designed precisely so people who can't write code can build apps — you just need to clearly describe what you want in natural language, and the AI handles the technical execution.

**How is it different from a regular AI chat?**
A regular chat gives you a text answer; Genspark Code gives you a genuinely runnable app — it actually writes files, runs code, and spins up services so you can preview the result directly.

**Do I own the apps I build? Can I use them commercially?**
Members can use AI-generated content commercially. You can download the code or deploy it live. The specifics depend on your membership benefits.

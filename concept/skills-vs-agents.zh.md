# Skills vs Agents — 什么时候用哪个

> For Buddy Agent internal use.
> type: concept | feature: skills | keywords: Skills, Agents, 对比, 区别, 选择, Claw

## 为什么要区分

Genspark 有 Skills 和 Agents 两种 AI 能力。用对了事半功倍，用错了浪费时间和 credit。

## 核心区别

| 维度 | Skills | Agents（Claw / Chat Agent） |
|------|--------|---------------------------|
| **定位** | 可复用的自动化任务模板 | 通用对话 AI |
| **适合** | 重复性工作、标准化输出 | 一次性问答、开放探索 |
| **配置** | 有 SKILL.md 指令文件，固定工具和流程 | 无固定指令，根据对话动态决定 |
| **输出** | 稳定、一致（同一 Skill 多次运行结果格式一致） | 灵活、因对话而异 |
| **外部数据** | 通过 Connectors 读取（Gmail、Sheets 等） | 主要靠搜索和用户上传 |
| **交付物** | 通常生成文件（报告、数据表、图表） | 通常是对话回复 |
| **创建成本** | 需要先创建 Skill（指令编写 + 测试） | 即开即用，无需准备 |

## 什么时候用 Skills

- 这个任务你**每周/每月都要做**（周报、竞品分析、数据清洗）
- 你需要**标准化输出**（团队里每个人做出来的格式一致）
- 任务需要**访问外部服务数据**（从 Gmail 读邮件、从 Sheets 读数据）
- 你想**分享给团队**，让别人也能一键完成

## 什么时候用 Agents

- **一次性问题**（"这段代码什么意思"、"帮我翻译这段话"）
- **探索性任务**（"帮我想想营销方案"、"分析一下这个市场"）
- **多轮对话**（需要反复追问、调整方向）
- **即时需求**（不值得花时间创建 Skill）

## 可以结合使用

Skills 运行在 Agent 基础上。你可以：
1. 先用 Agent 对话探索需求
2. 确定流程后，创建成 Skill
3. 以后每次运行 Skill 完成任务

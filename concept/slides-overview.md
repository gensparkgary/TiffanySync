## Why Use AI Slides

Building a PPT the traditional way takes 2–4 hours: brainstorm the structure → find a template → fill in content → adjust the layout → add images. AI Slides compresses this into **2–5 minutes**: describe what you want → AI generates a complete PPT → fine-tune the details → export.

Core value: **From one sentence to a ready-to-use presentation—research, structure, copy, images, and layout all handled by AI, while you simply make the call and fine-tune.**

## What Is AI Slides

AI Slides is Genspark's AI presentation tool that generates a complete PPT from a single prompt. It supports a wide range of scenarios, including business reports, social media posters, and educational courseware.

Entry point: `/ai_slides`, the "AI Slides" icon in the sidebar.

## Two Creation Modes

### Professional Mode

Ideal for scenarios that need clear structure, data visualization, and business communication. The output is a structured, standard PPT containing titles, body text, charts, lists, and other elements.

Supports the built-in editor (the toolbar's **Edit** mode, free manual editing) and the Skill Gallery (15 categories).

### Creative Mode

Ideal for scenarios that need visual impact: posters, social media images, and brand showcases. The output is a full-canvas visual design generated by AI, where every page is a complete AI image.

You can switch image models in the Image Model selector (subject to what's shown in the UI; see [Creative Mode](https://page.gensparksite.com/manual/buddy-guides/v1/en/slides-create-creative.md) for details).

### Comparing the Two Modes

| Dimension | Professional | Creative |
|------|-------------|----------|
| Focus | Structured business presentations | Full-canvas AI visual design |
| Output style | Text + charts + layout | AI-image-driven, poster/illustration style |
| Skill Gallery | ✅ 15 categories | ❌ Waterfall templates only |
| Image Model selection | — | ✅ Switchable (see [Creative Mode](https://page.gensparksite.com/manual/buddy-guides/v1/en/slides-create-creative.md)) |
| Built-in editor (Edit mode, free) | ✅ Supported | ❌ Not yet supported (go by what the interface shows) |

**Recommendations**:
- Business reports / data reports / training materials → **Professional**
- Social media carousels / posters / brand stories → **Creative**
- Not sure → **Professional** (more versatile)

## Guide Mode Toggle

Guide Mode isn't a third mode—it's a **standalone toggle** layered on top of either Professional or Creative. When enabled:
- The Agent first conducts a 4-phase (Strategy / Substance / Structure / Surface) in-depth consultation
- Then generates the PPT based on a full understanding

| Dimension | Default Mode | Guide Mode |
|------|---------|------------|
| Interaction | User enters a prompt → generates directly | Agent runs a 4-phase consultation → then generates |
| Best for | When you know exactly what you want | High-stakes scenarios where AI needs to deeply understand your needs |
| Time | Fast | Adds 5–10 minutes |

Recommended scenarios: investor pitch decks, board reports, key client proposals.

## Aspect Ratio Selection Guide

Choose before creating—**it cannot be changed afterward** (to switch ratios, you must create a new project).

| Aspect Ratio | Typical Scenarios |
|-------|---------|
| Auto | The default when you're unsure; AI decides automatically based on content |
| 16:9 | Meeting presentations, projection, video — the most common |
| 4:3 | Traditional projectors, printing |
| 1:1 | Instagram posts, LinkedIn |
| 3:4 | Posters, Xiaohongshu |
| 9:16 | Instagram Story, TikTok, Reels |
| 21:9 | Ultra-wide displays |

**Recommendations**:
- Vertical social media images → 9:16 or 3:4
- Square posts → 1:1
- Presentations / reports → 16:9
- Not sure → Auto

## The Slides Workspace and Editing Tools

A generated deck is edited in the **Slides workspace**: an outline thumbnail rail on the left, the stage in the center, zoom and the Notes panel at the bottom, and Present / Export / History buttons plus the ⋮ menu at the top. Above the slide sits the **Select / Draw / Edit** interaction-mode switch:

| Mode | Description | Consumes Credits |
|------|------|-----------|
| Select | Click any element (labeled by type) and give an instruction — AI changes exactly that spot | Yes |
| Draw | Circle/mark/box areas on any pages; marks collect into an edit queue sent in one go ("Send N edits") | Yes (when sent) |
| Edit | Built-in editor: manually change text/images/layout/page order/notes right on the canvas (Pro only) | No (free) |

**One-click AI refinements** (in the Select-mode toolbar; options vary by mode):

| Option | Mode | Description | Use Case |
|------|------|------|---------|
| Fix Layout | Pro | Fix layout issues | Content overflow, hard-to-read text, alignment drift |
| Polish Content | Pro | Strengthen content logic + layout | Overall optimization while keeping the style |
| Enrich Content | Creative | Expand details | The slide is too simple and needs more substance |
| Simplify Content | Creative | Streamline content | Information is too dense and needs distilling |
| Redesign Layout | Creative | Switch layout schemes | The layout is boring and needs creativity |

**Verify content**: verifies the facts, figures, and sources of the current page or the entire deck, leaves verification marks on slides, and writes the verification trail into speaker notes on PPTX export.

**Speaker Notes**: view and edit per-slide notes in the bottom Notes panel; click "Add notes" and AI interviews you about the occasion/audience/duration and writes the notes; notes travel with PPTX exports.

## Multi-File Projects

A single Project can contain multiple Slides files:
- **Deck tabs**: multiple decks appear as tabs across the top of the canvas — click to switch
- **Files view**: the folder icon at the top switches to a file browser covering all project files

## Scenario Selection Guide

Based on the intent described by the user, recommend the most suitable mode and settings:

```
What's the user's intent?
│
├─ "I want to build a PPT from scratch"
│   ├─ Content leans business/data/formal → Professional Mode
│   ├─ Content leans visual/poster/social → Creative Mode
│   └─ High-stakes scenario (pitch deck/report) → Enable Guide Mode
│
├─ "I have an existing PPT/PDF file"
│   ├─ Want to generate a new PPT based on it → Upload the file in the chat
│   └─ Want to copy and then modify → Make a Copy (⋮ menu)
│
├─ "I have a generated PPT and want to tweak it"
│   ├─ Minor changes (typos, colors, repositioning) → Edit built-in editor (free)
│   ├─ Edit a precise location → Select an element
│   ├─ Batch several changes → Draw annotations + Send N edits
│   ├─ Layout issues → Fix Layout
│   ├─ Overall optimization → Polish Content
│   └─ Data needs checking → Verify content
│
├─ "I want to export / share / present"
│   ├─ Export PDF/PPTX/Google Slides → the Export button at the top
│   ├─ Share a link → Share button
│   ├─ Present live → Present (incl. dual-screen Presenter view)
│   └─ Send a slideshow link → ⋮ menu → Presentation View
│
├─ "AI doesn't seem to remember what I said earlier"
│   └─ Memory is almost full → New Chat (saves credits, restores recall, can switch Tier)
│
└─ "I'm not sure how to do this"
    └─ Clarify the target audience and purpose, then pick one of the paths above
```

## Core Capabilities at a Glance

| Capability | Description |
|------|------|
| Create | Professional / Creative modes + Guide Mode + 7 aspect ratios |
| Edit | Select / Draw batch annotations / Edit built-in editor (free) / one-click AI refinements (by mode) / Verify content |

| Context | Memory indicator + New Chat (saves credits + can switch Tier) |

# Dashboards & CRM — Build a System

> For Buddy Agent internal use.
> type: howto | feature: agentbase | keywords: create, build a system in one sentence, template, Template Center, Just describe it, starter cards, CRM, inventory, recruiting, ask questions, workspace
> User loop: open /agentbase → describe it in one sentence or pick a template → answer clarifying questions → AI builds tables + fills data + creates the first view → land in a working workspace

## Why use it

- **From an idea to a working system in one sentence**: no need to figure out which tables you need or how to design the fields first. Just say "help me manage customers and deals," and the AI builds the entire database along with the first view.
- **Templates mean less typing**: common scenarios (CRM, inventory, recruiting, content calendar…) already have ready-made templates—pick one and customize from there.
- **The system you build is here to stay**: it's not a one-off result—it's a persistent workspace you can add data to, switch views in, and share anytime.

## Prerequisites

- Login required
- Entry point: the **Dashboards & CRM** tile on the home page → `https://www.genspark.ai/agentbase`
- The creation process is conversational and consumes credits based on usage for that round (browsing and selecting templates is free)

## Steps

### 1. Open Dashboards & CRM

Click the **Dashboards & CRM** tile on the home page; the URL ends up at `/agentbase`.

![Dashboards & CRM home page: ① one-sentence input box ② template entry ③ list of existing workspaces](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36683/daf39601.png)

At the top of the page is a large input box (the title reads roughly "Custom Dashboards, CRM, and Systems in minutes."), with templates and your existing workspaces listed below.

### 2. Option A: Describe it in one sentence

In the top input box, write a sentence describing what you want to manage, then submit. For example:

- "Help me manage customers and sales deals"
- "Build an inventory tracking system"
- "Set up a recruiting pipeline to track candidates and interview stages"

The input box cycles through example prompts you can reference. After submitting, you enter the conversational creation interface.

![Describe what you want to manage in one sentence in the input box](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36683/d09615c0.png)

Near the input box there are also **exactly 4 pre-filled starter cards**—click one to drop the corresponding prompt in:

- **From your inbox**—start by pulling data from your email (Gmail / Outlook, etc.)
- **From files**—start by uploading Excel / CSV / PDF / Word files or an entire folder
- **From another app**—start by connecting an app like HubSpot / Salesforce
- **Just describe it**—start entirely from scratch, just describing what you want to manage in one sentence (this is the starting point for "Option A" above, and also the way to start from a blank slate)

These are handy when you don't want to compose the wording yourself—one click fills in the prompt.

![Four starter cards: From your inbox / From files / From another app / Just describe it](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36683/686256c3.png)

### 3. Option B: Start from a template

If you'd rather not describe everything from scratch, click the template entry to open the **Template Center**. Here, ready-made templates are listed by scenario—category tabs on the left (My Systems / All Templates / Sales & CRM / Inventory / Projects / Marketing / HR & Recruiting / Personal, etc.) and template cards on the right, covering most common use cases.

![Template Center: category tabs on the left + template cards](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36683/3f66c969.png)

- **Clicking a template card** opens a preview dialog where you can see what the template looks like.
- In the preview dialog, click **Use this template** to build a system starting from that template.
- To start completely from scratch (a blank slate), you don't need to look here—go back to the home page and use the **Just describe it** starter card, or just describe it in the input box (see "Option A" above).

![Click a template card to open the preview dialog, then click Use this template to start from it](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36683/eca00548.png)

> Templates come with some sample data to help you see the structure clearly. Once you start writing in your own real data, the AI replaces the sample data for you—no manual cleanup needed.

### 4. Answer the AI's clarifying questions

To build a system that fits your needs, the AI usually asks you a few questions on **an interactive question card** before getting started—such as which fields you want to track and what stages to break things into. Just select options or fill in the card; no need to compose a long description yourself.

![The AI clarifies your needs with an interactive question card—just click to select](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36683/16e66f7a.png)

### 5. The AI builds the system and lands you in the workspace

Once you've answered, the AI automatically builds the tables it needs, fills in starter data, and generates the first ready-to-view view. When it's done, you land in this **workspace**—on the left you'll see the Dashboards / Tables / Workflows groups, and you can start viewing and using it.

![The workspace after the system is built: Dashboards / Tables / Workflows on the left, the generated tables and views on the right](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36683/d25fd99a.png)

From here you can keep chatting to have the AI make adjustments (add fields, change views, fill in data), or start [importing your existing data](https://page.gensparksite.com/manual/buddy-guides/v1/en/agentbase-import-data.md) and [building more views](https://page.gensparksite.com/manual/buddy-guides/v1/en/agentbase-views-and-dashboards.md).

## FAQ

**Can I build a completely different system in the same conversation?**
No. Once you enter a workspace, the current conversation focuses on it. To switch to another system or create a new one, go back to the home page and click a different workspace, or open a new conversation and start over.

**Where do I find the systems I built before?**
On the Dashboards & CRM home page, the **My Systems** section shows all your workspaces (each displays its table count and last update time). Click in to keep using one.

![The My Systems section on the home page lists all the persistent workspaces you've built](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36683/6cc5477e.png)

**Do I need to delete the sample data from a template myself?**
No. The sample data just helps you see the structure; when you start writing in real data, the AI replaces it automatically.

**What if I'm not happy with the table structure the AI built?**
Just tell it what to change in the conversation—add a column, delete a table, change what a field means, anything. The structure of the whole system can be adjusted through conversation anytime.

# AI Drive — Upload and Organize Files

> For Buddy Agent internal use.
> type: howto | feature: aidrive | keywords: drive, upload, folder, move, rename, search, preview, Recent Files, Shared with me
> User loop: Open /aidrive/files → upload files → create folder/move/rename to organize → list/grid view + Recent Files + search → preview files

## Why use Drive to organize files

- **One place for all your Genspark files**: the materials you upload and the files generated by every product all live in one spot, so you can come back and find them anytime without hunting around.
- **Easy to organize**: folders, move, rename, and search are all here, so you can quickly locate any file even among hundreds.
- **Preview directly**: view images, PDFs, PPTX, and videos online without downloading.

## Prerequisites

- Sign-in required
- Entry point: `https://www.genspark.ai/aidrive/files`, or "Drive" in the left sidebar

## Steps

### 1. Open Drive

Click "Drive" in the left sidebar, or go directly to `https://www.genspark.ai/aidrive/files`.

At the top of the page is the search box and storage usage; below is the file list. An empty Drive shows the "All files" empty state; once you have files, the root directory shows a "Recent Files" section.
![Drive home: search + usage at top, Recent Files, file list](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/35761/cb81742d.png)

Above the file area are **two tabs — "My Drive" and "Shared with me"**: My Drive holds your own files; Shared with me holds content others have shared with you (see the [sharing guide](https://page.gensparksite.com/manual/buddy-guides/v1/en/aidrive-share.md)).

### 2. Upload files

Click **"+ New"** in the top right, then choose **Upload** (upload files) or **Upload Folder** (upload an entire folder) from the dropdown. You can also **drag and drop** files directly onto the page (the empty state shows a "drag files here" prompt).
![Upload / Upload Folder buttons and drag-and-drop upload](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/35761/df7061ab.png)

### 3. Create a folder

In the **"+ New"** dropdown, choose **"New Folder"**, enter a folder name, and confirm to create it (toast: "Folder created successfully").

### 4. Move and rename

Select a file (check the checkbox), and an action bar appears at the top: **Share / Rename / Download / Move / Delete**. Among these:
- **Move**: opens a directory picker to move the file to a target folder
- **Rename**: rename the file
![Action bar after selecting a file: Share / Rename / Download / Move / Delete](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/35761/5f517dcf.png)

### 5. List / grid view and sorting

The file area supports switching between **list** and **grid** views. You can sort by **Name / Size / Modified**.

At the top of the root directory, **"Recent Files"** displays recently accessed files horizontally; click to open them quickly.

### 6. Search

Use the search box at the top ("Search files and folders") to find files. Results return instantly as you type, and each result is labeled with its location (e.g. "All files" or the folder it's in).

### 7. Preview files

Double-click a file to open a full-screen preview, which supports viewing common types like images, PDFs, PPTX, and videos online. **.zip archives can also be previewed directly** — you can browse the files inside without extracting first. Image previews can also be cropped/rotated and saved back to Drive. Types that don't support online preview will prompt you to download directly.
![Full-screen preview: view images/PDF/PPTX online](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/35761/467b4a34.png)

## Notes

- File management actions (upload, organize, preview) **don't consume credits** — they're free to use.
- Uploads are limited by your Drive space (**capacity varies by plan; refer to the usage bar at the top of the interface**); when space is full, you'll be prompted to upgrade.
- **On first use, an "AI Drive Legal Disclaimer" appears first** (covering copyright / user responsibility / content safety, etc.); you must check "I have read and agree" and click I AGREE before you can upload/download.
- Item-by-item progress and results for operations like upload/download/move/compress are shown in the **Status / Operations panel at the bottom right of the page** (e.g. "Successful", "Moved 1/1 Completed").
- Deleted files go to the Trash first and can be restored — see [Download and Organize](https://page.gensparksite.com/manual/buddy-guides/v1/en/aidrive-download-and-organize.md) for details.

## FAQ

**Q: Is there a size limit for uploads?**
It's limited by your total Drive space; the per-file limit follows the on-screen prompt.

**Q: Can I recover something I deleted by mistake?**
Yes. Deleted files go to the Trash and can be restored. See [Download and Organize](https://page.gensparksite.com/manual/buddy-guides/v1/en/aidrive-download-and-organize.md).

# AI Docs — Create from a Template

> For Buddy Agent internal use.
> type: howto | feature: ai-docs | keywords: templates, Template, template gallery, Template Gallery, resume, job search, report, form, blank document
> User loop: Open AI Docs → browse/pick a template by category in the right-side gallery (or Blank) → create from the template → edit

## Why use a template

When you don't want to start from a one-line description and already have a clear document type in mind (resume, business letter, report, form…), just grab the closest match from the template gallery and create from it. It's faster than generating from scratch and gives you a more reliable layout.

## 1. Find the template gallery

Once you're in AI Docs (`/ai_docs`), **the template gallery is laid out in the right-side panel by default**—a masonry of thumbnails, no extra click needed. At the top you'll find category tags and two tabs: **All Templates** / **My Docs** (My Docs holds documents you already have).
![Template gallery: category tabs + My Docs + Blank document card](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/35537/add5ff39.png)

## 2. Browse by category

The category tags at the top let you switch your browsing by purpose, covering directions such as (refer to the UI for the exact list):

- Job search (resumes, cover letters, etc.)
- Business communication
- Reports and analysis
- Forms and surveys
- Legal and finance
- Education and training
- Creative and marketing

The gallery has **hundreds of templates** covering common document scenarios. Refer to the UI for the exact categories and counts.

## 3. Pick a template (or a blank document)

- Click a thumbnail to preview/select a template
- Or choose the **Blank document** card (top-left of the gallery) to start a blank document from scratch

## 4. Create from the template

Once you select a template, AI Docs creates a new document based on it. After creation you're in the normal editing flow—just replace the placeholder content in the template with your own.

> Creating from a template consumes credits (billed by AI workload); refer to your balance before and after for the exact amount.

## Template vs. describing from scratch—which to choose

| Situation | Recommendation |
|------|------|
| You know the exact document type (resume, contract, report…) | Use the template gallery for a ready-made layout |
| Unique needs / want to let AI run free | Describe it directly in the input box (see [Create a Document](https://page.gensparksite.com/manual/buddy-guides/v1/en/docs-create.md)) |
| You want a completely blank canvas to write yourself | Choose the Blank document card in the gallery |

## FAQ

### How many templates are in the gallery?
Hundreds of templates spanning directions like job search, business, reports, and forms, browsable by category. Refer to the UI for the exact count and categories.

### What is the My Docs tab?
The My Docs tab at the top of the template gallery holds documents you've already created, so you can quickly jump back to an existing document and keep editing. Each document card has a three-dot (⋯) menu where you can **rename** or **delete** that document.

### Can I still make major changes after picking a template?
Yes. After you create from a template, it's just a regular document—both AI editing and manual editing are available. See [Edit and Export](https://page.gensparksite.com/manual/buddy-guides/v1/en/docs-edit-and-export.md).

### Are the quick-start tasks the same thing as the template gallery?
No. The few "quick-start tasks" below the input box are sample prompts (clicking one fills it into the input box); the template gallery is the large collection of finished templates laid out in the right panel by default (browsable by category). For a ready-made layout, use the template gallery.

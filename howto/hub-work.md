# Hub — Working in a Hub

> For Buddy Agent internal use.
> type: howto | feature: hub | keywords: Hub, Recent Tasks, cross-project, referencing history, project ownership, Add to Hub, Change Hub, downloading files, reorder, archive
> User loop: Enter a configured Hub → find/continue a project in Recent Tasks → reference conclusions from earlier projects in a new chat → manage project ownership → download outputs → organize your Hub list

## Why work in a Hub

Once a Hub is set up, its real value shows up in daily use: every new chat automatically carries your files and rules, and you can directly reference conclusions from earlier tasks in the same Hub to keep building on them. All related projects live on one home page you can revisit anytime—you keep making progress in a space that "remembers the whole project," instead of starting from scratch every time.

## Prerequisites

- Entry: `https://www.genspark.ai/hub`, then open an existing Hub
- Requirements: a signed-in account, and at least one Hub created or joined

## Steps

### 1. Open a Hub and view Recent Tasks

After opening a Hub, the home page's **Recent Tasks** lists all projects in that Hub (with Search Chats next to it). Click any one to view its history or continue earlier work. Once a chat started in that Hub finishes, it automatically appears here.
![Recent Tasks project list on the Hub home page](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/35760/9ad76079.png)

### 2. Reference earlier projects in the same Hub

When you start a new chat inside a Hub, you can directly reference conclusions from earlier projects in that Hub, and Genspark will automatically retrieve and apply the relevant history. For example:
- "Based on last week's market research project, create a competitive analysis"
- "Referencing yesterday's meeting notes project, draft an action plan"
- "Update the Q4 forecast based on the conclusions from the Q3 analysis"

> This is what sets a Hub apart from ordinary chats: ordinary chats are each independent, while projects in a Hub share history and can pick up where others left off.

### 3. Manage project ownership

A project can belong to a Hub, and it can also be moved or removed. Each project can only belong to one Hub at a time. Manage ownership in a project's **⋯ menu**:
- **A project not yet in any Hub**: the menu shows **Add to Hub**—pick a Hub to add it to.
- **A project already in a Hub**: the menu shows **Change Hub** (move it to another Hub) and **Remove from Hub** (take it out).

Three ways to open the ⋯ menu:
- **On the Hub home page**: hover a task → click **⋯**
- **Inside a project**: **⋯** in the top right
- **In the Task List**: open the Task List in the top left, then click **⋯** on a project

> The same ⋯ menu also includes general project actions like **Pin / Bookmark / Rename / Delete**; ownership management (Add/Change/Remove from Hub) is one group within it.

![Project ⋯ menu (Pin / Bookmark / Rename / Change Hub / Remove from Hub / Delete)](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/35760/a5319eda.png)

### 4. Download files from a Hub

On the Hub home page, click **Files**, then **click a file name** to download that file to your local device.

### 5. Organize your Hub list: reorder and archive

The "Your Hubs" list page has two tabs, **Active / Archived**, so hubs you're actively driving stay separate from ones that have wrapped up:

- **Drag to reorder**: on the Active tab, **drag a Hub card** to change its position (with more than one Hub, the page shows a "Drag to reorder" hint); the order is saved as soon as you drop. This order only affects your own view of the list—it doesn't change how other members see theirs.

- **Archive a Hub (creator only)**: when a Hub is no longer active, archive it—on the Your Hubs page, hover the Hub → **⋯ → Archive hub**, or inside the Hub, top-right **⋯ → Archive hub**. Archiving takes effect immediately with no confirmation dialog (it's reversible anytime); the Hub moves to the **Archived** tab (sorted by archive time), and this applies to all members.

- **Archiving doesn't limit usage**: an archived Hub works exactly as before—files, history, and chats all remain available; the only difference is a "This hub is archived." banner at the top, which is a reminder and never blocks anything. The creator can click **Unarchive** right on the banner (or **Unarchive hub** in the ⋯ menu) to restore it; the Hub then returns to the end of the Active list.

## FAQ

**How many projects can a Hub hold?**
There's no hard limit. The results depend on the relevance of the retrieval, not the total number of projects.

**Can a project belong to multiple Hubs at once?**
No. Each project can only belong to one Hub at a time, but you can move it anytime.

**Do chats in a Hub consume credits?**
Yes, just like ordinary chats. When a Hub has many files and a large context, the consumption is higher—so adding only truly relevant files and naming which file to use when you ask saves credits.

**Can I export files from a Hub?**
Yes. Go to Files → click a file name to download it. Files are stored persistently with no time limit.

**Does archiving a Hub delete anything?**
No. Archiving only moves the Hub to the Archived tab—files, projects, and history are all kept, the Hub stays fully usable when opened, and you can unarchive it anytime.

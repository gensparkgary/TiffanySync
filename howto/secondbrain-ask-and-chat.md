# Second Brain — Ask & Chat

> For Buddy Agent internal use.
> type: howto | feature: secondbrain | keywords: Second Brain, Ask, Chat, ask, chat, Standard, Ultra, tier, @ reference, attachments, memory cards, chat history
> User journey: three ask entry points (Home box / full-page Chat / editor panel) → pick a tier (Standard/Ultra) → @ references / attachments / file references → understand answers & artifacts (docs / slides / memory cards) → chat history

## Why use Ask / Chat

- Ask once, get answers across your email, meeting notes, notes, and connected apps—no more digging through every app yourself
- Artifacts land straight in your space: the docs it writes, the slides it builds, the key facts it saves all stay in your Second Brain, ready to find again
- Predictable spend: use the default Standard tier for everyday quick questions, and switch to Ultra only when you need deeper reasoning

## Prerequisites

- Entry point: https://www.genspark.ai/second-brain/home
- Requirements: signed in to a Genspark account; desktop browser
- Credits: asking spends credits based on usage, and the tier affects the cost; connecting data sources makes answers more accurate (connecting itself is free, see [Connect data sources](https://page.gensparksite.com/manual/buddy-guides/v1/en/secondbrain-connect-sources.md))

## Steps

### 1. Three ways to ask

- **The Ask input box on Home**: the most common entry point
- **Full-page Chat**: a complete chat page, great for long multi-turn conversations
- **The "Ask Second Brain" panel on the right of the editor**: press **⌘J** while writing a doc to bring it up and ask as you write

![Press ⌘J in the editor to bring up the Ask Second Brain panel on the right (with the current doc automatically added as context)](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/48743/a58673b5.png)

### 2. Pick a tier: Standard or Ultra

Choose from the tier dropdown next to the input box:

- **Standard** (default): everyday quick questions
- **Ultra**: deeper reasoning, **notably higher credit cost**—the first time you switch, a confirmation dialog appears and only takes effect after you confirm

![The tier dropdown next to the input box: Standard (default) and Ultra](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/48743/da29db07.png)

![The confirmation dialog the first time you switch to Ultra, warning of a notably higher credit cost](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/48743/74e93e95.png)

### 3. Give your question context

- Type **@** to reference your own files or folders so the answer focuses on the specified content
- Click **(+)** to add attachments: local files or files from AI Drive
- Hover over a file or folder in the sidebar file tree and click **Reference in chat** to bring the whole thing into the conversation as an @ reference

![Type @ to open a reference list of your own files/folders](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/48743/fa6745d9.png)

### 4. Understand answers & artifacts

It answers across your connected and imported data sources, and checks which sources are actually connected before it starts. Beyond the answer, it may include artifacts:

- **Files**: written straight into your docs area
- **Docs / Slides**: the answer includes an **inline link** to the artifact—click it to jump into the editor and keep editing
- **Memory cards**: key facts automatically captured during the conversation, saved to your memory and **editable** later

You can rate each answer 👍/👎. Note: asking it to do heavy work in chat—like building slides or writing long docs—is billed separately by the corresponding product and spends more credits.

![Answering across data sources: it checks connected sources before it starts](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/48743/dc8bca21.png)

![Click the inline artifact link in the answer to open the editable editor](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/48743/63f71e8e.png)

### 5. Find and start conversations

Click the history button on the left of the composer to open a dropdown: **Search conversations** to find past conversations by keyword, and **New chat** to start a fresh one.

![The history dropdown: the Search conversations box and New chat](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/48743/4c99816d.png)

## FAQ

**Q: How is asking billed?**
Credits are spent based on usage, and the tier affects the cost: Standard (default) is for everyday quick questions, while Ultra reasons more deeply and costs notably more (with a confirmation dialog the first time you switch). Browsing docs, viewing the graph, and connecting and syncing data sources don't spend credits. For the full breakdown, see [Product overview](https://page.gensparksite.com/manual/buddy-guides/v1/en/secondbrain-overview.md).

**Q: How does it know my email and meeting content?**
You need to bring your data sources in first: email and meeting notes can be imported, and apps like Notion and Slack can be connected for real-time reading. See [Connect data sources](https://page.gensparksite.com/manual/buddy-guides/v1/en/secondbrain-connect-sources.md).

**Q: Where are memory cards stored? Can I fix them if they're wrong?**
They're saved to your memory and, just like the Memory doc, are editable anytime—everything it remembers is visible and editable by you. See [Product overview](https://page.gensparksite.com/manual/buddy-guides/v1/en/secondbrain-overview.md).

**Q: How are credits counted for slides I ask it to build?**
This kind of delegated heavy work is billed separately by the corresponding product and costs more than ordinary Q&A; the resulting files stay in your docs area. For how to manage them, see [Write notes & manage docs](https://page.gensparksite.com/manual/buddy-guides/v1/en/secondbrain-notes-and-files.md).

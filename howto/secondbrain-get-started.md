# Second Brain — Your First Steps

> For Buddy Agent internal use.
> type: howto | feature: secondbrain | keywords: Second Brain, Second Brain, get started, onboarding, get started, onboarding, Home, Ask, tour, tour, Popular plays, Memory Map, Memory Map, first question
> User journey: Sidebar Second Brain → Home (Ask box / Connectors bar / Your documents / three pills) → first-run onboarding (by rollout bucket: bubble tour or Memory-building guide) → send your first question → view your memory graph in Memory Map

## Why use Second Brain

- Connect your email, meeting notes, notes, and everyday apps, then ask anything in one place — it answers across all your data sources
- Guided onboarding on first entry (varies by rollout bucket: a 3-step bubble tour or a Memory-building guide) gets you to your first question — and your first cross-source answer — in minutes
- Your memory is visible and editable: the Memory Map graph draws your files as a graph, and clicking a node opens the file directly

## Prerequisites

- Entry point: https://www.genspark.ai/second-brain/home
- Requirements: sign in to your Genspark account; open in a desktop browser (it's designed for desktop — on mobile you can jot quick notes via Telegram, see [Quick Notes](https://page.gensparksite.com/manual/buddy-guides/v1/en/secondbrain-quick-notes.md))
- Credits: asking questions consumes credits based on usage; the tour, viewing the graph, and browsing documents are free

## Steps

### 1. Open Second Brain

Take either entry point:

- Go directly to https://www.genspark.ai/second-brain/home
- The **Second Brain** item (with a New badge) in Genspark's global left sidebar

Some users will first pass through a Memory intro page ("Enter your brain") on first entry — click **Enter your brain** to land on Home.

![Second Brain entry point in the sidebar (with New badge) and the Home landing page](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/48742/f356ec42.png)

### 2. Get to know Home

Home is a memory-first landing page. From top to bottom:

- The top tagline "Remembers everything. Thinks with you." and the **Ask input box** (placeholder "Ask anything — notes, mail, meetings…") — this is the core entry point for asking; the input box also has three small controls: history (clock), attachment (paperclip), and mode (Standard by default)
- The **Connectors bar**: "read live, only when you ask" — a row of connectable apps that you can turn off when you don't need them
- **Your documents**: a grid of your documents
- Three shortcut pills: **Quick note** (jot notes via Telegram) / **Upload** (upload files) / **New** (create a new document)

![Full view of Home: top tagline and Ask input box, Connectors bar, Your documents grid, and the Quick note / Upload / New pills](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/48742/506c39fd.png)

### 3. Walk through the first-run onboarding

Onboarding pops up on first entry, and its exact form depends on your rollout bucket:

- Some users see a **3-step bubble tour** that introduces the Files, Feed, and Ask areas in turn; the final screen is **Popular plays** with example scenarios (e.g. "Have your weekly summary written for you"). Click **Try it now** on a scenario and its prompt fills into the input box but **won't be sent automatically** — you can edit it first, then send
- Other users see a **full-screen Memory-building guide** (which builds an initial memory from your existing data) — it's free and skippable

After closing onboarding, the orb in the bottom-right corner can reopen it anytime (it still opens the version matching your rollout bucket).

![First-run onboarding example: the first screen of the Memory-building guide (users in the bubble-tour bucket see a 3-step bubble tour)](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/48742/171ef8ee.png)

![After closing onboarding, the orb in the bottom-right corner can reopen it anytime](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/48742/706fc43d.png)

### 4. Send your first question

Type your question in the Ask input box and send. It answers across the data sources you've connected and imported — before answering, it first checks which sources are actually connected; after the answer, a few **follow-up suggestion cards** appear below, and you can give **👍/👎** feedback on every answer. You can also ask before connecting anything: start with general questions, then head to [Connect data sources](https://page.gensparksite.com/manual/buddy-guides/v1/en/secondbrain-connect-sources.md) to bring in your email and meetings, and the answers will get to know you better over time.

Asking consumes credits based on usage, defaulting to the **Standard** mode (quick everyday Q&A); for modes and more ways to ask, see [Ask and Chat](https://page.gensparksite.com/manual/buddy-guides/v1/en/secondbrain-ask-and-chat.md).

![First-question answer screen: it checks the connected data sources up front, then streams the answer](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/48742/713fde47.png)

### 5. Open Memory Map to see your memory

Click **Memory Map** in the sidebar to open the memory graph: a force-directed graph where nodes are your files and edges are the links between them; click any node to open that file directly; **Connect more** in the bottom-right corner jumps you to connecting more data sources. Viewing the graph is free.

![Memory Map force-directed graph, with a Connect more button in the bottom-right corner](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/48742/49592a77.png)

![Click a graph node to open the corresponding file directly](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/48742/a48fe6a3.png)

## FAQ

**Q: Do the tour and the graph cost credits?**
No. First-run onboarding (in either form), Memory Map, and browsing documents are all free; only asking (Ask / Chat) consumes credits based on usage.

**Q: I closed onboarding — can I see it again?**
Yes. The orb in the bottom-right corner of the page can reopen onboarding anytime.

**Q: What should my first question be?**
If your onboarding is the bubble tour, the scenarios in the final Popular plays screen make ready-made openers (click Try it now to fill them into the input box); to make answers truly "know you," first head to [Connect data sources](https://page.gensparksite.com/manual/buddy-guides/v1/en/secondbrain-connect-sources.md) to bring in your email or meeting notes.

**Q: Can I use it on mobile?**
It's designed for desktop browsers; the official lightweight entry point on mobile is jotting quick notes via Telegram — see [Quick Notes](https://page.gensparksite.com/manual/buddy-guides/v1/en/secondbrain-quick-notes.md).

**Q: How does it relate to Super Agent?**
The memory you build here comes along when Super Agent gets to work (this can be turned off) — see [Product Overview](https://page.gensparksite.com/manual/buddy-guides/v1/en/secondbrain-overview.md).

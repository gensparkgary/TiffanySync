# AI Slides — Creating with Creative Mode

> For Buddy Agent internal use.
> type: howto | feature: ai-slides | keywords: Creative, creation, poster, social media, AI image generation
> User loop: /ai_slides → choose Creative → pick aspect ratio → pick Image Model → enter prompt → generate full-canvas AI design → edit/export

## Why Use Creative Mode

- **Create eye-catching visuals**: Every page is a full-page AI image, more like a poster than a traditional slide deck — ideal for scenarios that need strong visual impact
- **Crank out social posts in one go**: Instagram carousels, Xiaohongshu vertical images, TikTok covers — pair with portrait ratios to produce publish-ready content directly
- **No need to hunt for assets**: The illustrations you want are generated by AI right on the page, and you can switch between image models to match different styles
- **Look professional without design skills**: Describe the style you want in natural language and let AI handle the layout and imagery

## Prerequisites

- Login required
- Creative Mode requires a paid membership (free users will see an upgrade prompt)
- Entry point: `/ai_slides` or the AI Slides icon in the sidebar

## Steps

### 1. Switch to Creative Mode

Click the **"Creative"** tab on the creation page. On the first switch, users without the required membership see the **"Unlock Creative Mode"** dialog, with **Upgrade to Unlock** and **Continue Browsing** buttons — upgrade, or keep browsing the templates.

!["Unlock Creative Mode" dialog shown to non-members (Upgrade to Unlock / Continue Browsing)](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/51105/f3a2c134.png)

![Creative Mode selection](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36124/53216ee6.png)

### 2. Choose an Aspect Ratio

Aspect ratio selection in Creative Mode is the same as in Professional (Auto / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / 21:9).

Recommendations for social media:
- Instagram post → **1:1**
- Instagram Story / TikTok → **9:16**
- Poster / Xiaohongshu → **3:4**

![Aspect ratio selection](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36124/e574a3bc.png)

### 3. Choose an Image Model (Optional)

The Image Model selector is unique to Creative Mode and lets you switch between different image models — each is good at different styles (go by the options shown in the UI):

- **GPT Image 2** (default) — general illustrations, photo-style images, text rendering
- **Nano Banana Pro** — artistic illustrations, abstract backgrounds, rapid iteration

**Recommendation**: when in doubt, use the default GPT Image 2; switch to Nano Banana Pro for a more artistic style or faster iteration.

![Image Model selector](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36124/95642966.png)

### 4. Browse and Choose a Template (Optional)

A waterfall of template cards appears below in Creative Mode. Hover over a card to preview its carousel, and click a template to auto-fill it into the input box.

![Creative Mode template waterfall](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36124/6d2a7b06.png)

### 5. Enter a Prompt and Generate

Describe the visual you want, for example:
- "Cyberpunk style product launch for a tech startup"
- "Watercolor travel blog carousel about Japan in autumn"

The Agent starts generating a full-canvas AI design.

![Prompt input box](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36124/64f09372.png)

### 6. Review and Edit the Result

Once generation is complete, each slide is a full AI image, viewed and edited in the Slides workspace:

- **Draw annotations (on by default)**: Creative projects start in annotation mode — circle the areas you want changed directly on the visual and jot a note for each; mark several spots and send them all at once
- **One-click AI refinements**: Enrich Content / Simplify Content / Redesign Layout
- **Verify content**: verify the accuracy of the content in the visuals
- **Edit built-in editor**: not yet supported in Creative Mode (go by what the interface shows)

## FAQ

- **Can free users use Creative Mode?** No. Creative Mode requires a paid membership; users without it see the "Unlock Creative Mode" prompt (Upgrade to Unlock / Continue Browsing) when switching to it.
- **How do I choose between Creative and Professional?** Use Creative when you want full-page visuals, like posters or social media images; use Professional for structured business presentations (bullet points, charts, lists).
- **Can I manually edit text and images in Creative Mode like in Professional?** Not yet — the Edit built-in editor is not yet supported in Creative Mode (go by what the interface shows). For now, use the default-on Draw annotations and the one-click refinements (Enrich / Simplify / Redesign Layout) to make adjustments.
- **Which image model should I pick?** When in doubt, use the default GPT Image 2; switch to Nano Banana Pro for a more artistic style or faster iteration (go by the options shown in the UI; see "Choose an Image Model" above).

# AI Slides — Using Guide Mode

> For Buddy Agent internal use.
> type: howto | feature: ai-slides | keywords: Guide Mode, deep consultation, high quality, pitch deck, 4 phases
> User loop: Pick a mode → Turn on Guide Mode → Enter initial prompt → 4-phase deep consultation → Agent fully understands your needs → Generate a high-quality deck

## Prerequisites

- You're on the `/ai_slides` creation page
- You've selected Professional **or Creative** mode (Guide Mode can be enabled on either mode)
- Your account has enough credits (Guide Mode consumes credits throughout both consultation and generation; a 0 balance will block it entirely)

## Why use Guide Mode

- **Significantly higher generation quality**: The 4-phase deep consultation lets the AI fully understand your audience, goals, materials, and structure, producing results far more precise than a one-line prompt
- **Ideal for high-stakes scenarios**: Investor pitch decks, board presentations, client proposals—these are worth the extra 5–10 minutes to get a deck that truly fits your needs
- **Less rework later**: The more thorough the upfront communication, the fewer AI editing passes you'll need afterward—actually saving credits
- **No prompt-writing skills required**: Not sure how to describe your needs? Guide Mode proactively asks you—just answer the questions

## What is Guide Mode

Guide Mode is a standalone button (pill-shaped; lit up means enabled) that layers on top of Professional or Creative mode. Once enabled, the Agent won't generate right away—instead, it runs a **4-phase deep consultation** first, where each phase includes multiple rounds of questions and an approval gate (you confirm before moving to the next phase), so it fully understands your needs before generating.

## Steps

### 1. Turn on Guide Mode

Find the **Guide Mode** button (a pill button with an icon and text) in the settings bar and click it so it **turns blue and highlights**, indicating it's enabled.

![Guide Mode off state](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36194/2cfbfbd4.png)

![Guide Mode on state (blue highlight)](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36194/a0645981.png)

### 2. Enter the initial prompt

Briefly describe your presentation topic in the input box, for example:
- "Series A pitch deck for our AI customer service startup"

Click send.

### 3. Complete the 4-phase consultation

The Agent will guide you through the 4 phases of deep consultation in order:

| Phase | Name | Purpose |
|------|------|------|
| Phase 1 | **Strategy** | Define audience, core message, and strategic positioning |
| Phase 2 | **Substance** | Research supporting data and facts |
| Phase 3 | **Structure** | Settle the outline and page structure |
| Phase 4 | **Surface** | Settle the visual style and branding |

Each phase includes **multiple rounds of questions + an approval gate** (the Agent summarizes the current phase's outcome, and you confirm before moving to the next phase). You can also choose **"Skip to build"** to skip the remaining phases and generate directly.

The more detailed your answers, the higher the generation quality.

![Guide Mode first consultation round (Agent asking about the audience)](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36194/9660797e.png)

### 4. The Agent generates the deck

Once all phases are complete (or skipped), the Agent generates the deck based on its full understanding. Because the Agent already knows your specific needs, the result usually fits your expectations much better than a direct prompt would.

![Guide Mode generation result](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/34005/ce2d978e.png)

### 5. Further editing

After generation, you enter the Slides workspace, where you can keep refining with tools like Select, Draw annotations, the Edit built-in editor, one-click AI refinements, and Verify content.

![Creative + Guide Mode layered independently](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36194/9e5a9402.png)

## FAQ

**Q: Does Guide Mode take a lot more time?**
A: The 4-phase consultation usually adds 5–10 minutes, but in return you get a deck that fits your needs much better—and you'll need fewer AI editing passes afterward.

**Q: What if I don't want to go through all 4 phases?**
A: At any phase you can choose **"Skip to build"** to skip the remaining phases and have the Agent generate right away.

**Q: Can I use Guide Mode together with Creative mode?**
A: Yes. Guide Mode is a standalone button that layers on top of Professional or Creative mode—they don't replace each other.

**Q: Does the consultation process also consume credits?**
A: Yes, both the consultation and generation consume credits throughout, and a 0 balance will block it entirely.

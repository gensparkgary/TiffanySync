# AI Slides — Importing Existing Files

> For Buddy Agent internal use.
> type: howto | feature: ai-slides | keywords: Import, PPTX, PDF, Upload, Import
> User loop: Existing PPTX/PDF → Upload to the Agent in chat → Agent parses and converts it into editable Slides → Continue refining with AI editing

## Why Use the Import Feature

- **Don't start from scratch**: Already have a report or presentation? Just upload it and let AI build on it — far faster than describing everything again
- **PPTX keeps your layout**: The layout and styling of your company-branded PPT is preserved as much as possible
- **PDF content extraction**: Key content from PDFs like research reports and whitepapers can be automatically extracted and turned into a PPT
- **Cross-format reuse**: Turn a PDF report into a presentable set of Slides with one-click format conversion

## Prerequisites

- You've entered an AI Slides project
- You have a PPTX or PDF file to import

## Steps

### 1. Upload a File in Chat

In the chat input box with the Agent, click the **"+"** button and choose:
- **Browse Local Files** — upload a PPTX or PDF file from your computer
- **Choose from AI Drive** — pick an existing file from AI Drive

Note: the "+" menu itself doesn't label any format restrictions — the entries just read "Browse Local Files" / "Choose from AI Drive".

You can upload multiple files at once.

![Upload entry point (the "+" button and menu options)](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36199/2a0629f7.png)

### 2. Tell the Agent What You Want

After uploading, just describe what you want to do, for example:
- "Convert this PPT into editable Slides"
- "Generate a new PPT based on the content of this PDF"
- "Make an English presentation based on this report"

### 3. The Agent Parses and Generates

The Agent parses the file content and generates or converts it into AI Slides according to your request. Once done, you enter the normal editing view.

![Parsing file in progress](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36199/708c80df.png)

![Import generation result](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36199/7c3deba0.png)

### 4. Keep Editing

Imported Slides support all editing features: Select / Draw annotations, the Edit built-in editor (free), one-click AI refinements, and Verify content.

## Notes

- After a PPTX import, the original layout is preserved as much as possible
- A PDF import mainly extracts content, so the layout may change
- Slides generated from an import are all Skills (not templates), and can be saved for reuse via Save as Skill

## FAQ

**Will the layout look exactly like the original file after importing?**
PPTX preserves the original layout as much as possible; PDF mainly extracts content, and the layout is regenerated by AI Slides, so it may differ from the original file.

**Can I upload multiple files at once?**
Yes. Use the "+" button in the chat input box to select and upload multiple files together, then tell the Agent how you want to use them.

**Can I keep editing with AI after importing?**
Yes. Imported Slides support all editing features: Select / Draw annotations, the Edit built-in editor (free), one-click AI refinements, and Verify content.

**What's the difference between local files and AI Drive files?**
It's just the source: Browse Local Files uploads from your computer, while Choose from AI Drive picks from files you've already saved. They're processed the same way after importing.

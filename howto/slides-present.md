# AI Slides — Presenting

> For Buddy Agent internal use.
> type: howto | feature: ai-slides | keywords: Present, Presenter view, Presentation View, fullscreen, presentation, slideshow, Play Slides, speaker console
> User loop: Finish deck → click Present → fullscreen show (navigate / draw) → use Presenter view for dual-screen setups → use Presentation View for a shareable link → exit when done

## Why use the presenting features

- **No download needed**: Present fullscreen right in the browser—no need to export PPTX and open PowerPoint
- **Annotate while you talk**: Use the drawing pen during the show to circle key points, and clear them anytime
- **Pro dual-screen presenting**: Presenter view gives you a speaker console—notes, next-slide preview, and a timer—while the audience sees only clean slides
- **Any device**: Present from any browser, no specific software required

## Prerequisites

- A deck has been generated and you're in the Slides workspace
- You have a scenario to present (meeting, classroom, talk)

## Option 1: Present (fullscreen right in the workspace)

### 1. Start the show

Click **"Present"** at the top of the workspace — the show enters fullscreen right away, starting from the slide you're currently on. There is no pre-show menu; the presenting tools (Presenter view, Draw on page, Exit) live in the bottom-right toolbar during the show.

### 2. Controls while presenting

During the show, two floating control pills sit in the bottom corners of the screen (the middle stays clear so slide content isn't covered):

- **Bottom-left**: previous slide / page counter / next slide
- **Bottom-right**: **Draw on page** (a pen for circling key points live), clear drawings on this page, Presenter view, fullscreen toggle, and exit

![In-show floating control pills — page navigation bottom-left, Draw on page / Presenter view / Exit bottom-right](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/51105/489a9ee9.png)

### 3. Exit

Click the exit button in the bottom-right tools (or leave fullscreen) to return to the workspace.

## Option 2: Presenter view (dual-screen speaker console)

Best for formal pitches and reports: your screen shows the speaker console, while the audience screen shows nothing but clean slides.

1. Click **"Present"** to start the show, then click **"Presenter view"** in the bottom-right toolbar
2. The speaker console opens in its own window: current slide, next-slide preview, speaker notes (with adjustable text size), and a timer (pause/resume/reset)
3. Move the audience window to the projector or second display and make it fullscreen
4. Drive the show from your console—both windows stay in sync, and your cursor is mirrored on both displays so you can guide the audience's attention

Note: if your browser blocks pop-ups, allow pop-ups for this site to open the presenter console.

## Option 3: Presentation View (shareable slideshow in a new tab)

When you need a **shareable slideshow page** (e.g. a link others can simply open and watch), click the **⋮ menu** at the top right of the workspace → **"Presentation View"**. The browser opens a read-only preview page in a **new tab**.

The preview page displays all slides in a scrolling view, with the page count at the top (e.g., "5 pages total") and the current position (e.g., "1 / 5"), along with **"Play Slides"** and **"Export"** buttons.

![Read-only preview page](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36126/fed6624d.png)

Click **"Play Slides"** to enter the browser's fullscreen slideshow mode:

![Fullscreen slideshow](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36126/66cdf8ad.png)

- **Next slide**: press the **→** key; **previous slide**: press the **←** key
- Press **Esc** to exit fullscreen and return to the preview page

![Navigating with arrow keys](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/36126/f5132af9.png)

Edits to the original project are instantly reflected on this slideshow page, so you can present and tweak on the fly.

## Use cases

- Live screen-sharing in meetings → **Present** (for pen annotations) or **Presenter view** (for notes and the timer)
- Sending a slideshow link for others to watch on their own → **Presentation View**
- Previewing the final result (how the layout looks on a big screen) → **Present** or Presentation View
- Rehearsing before recording a presentation video → **Presenter view** (it has a timer)

## FAQ

**What's the difference between Present and Presentation View?**
**Present** runs a fullscreen show right inside the workspace, with presenting tools like the drawing pen and Presenter view; **Presentation View** opens a shareable slideshow page in a new tab—ideal for sending the link to others.

**How do I draw on slides while presenting?**
During a Present show, turn on **Draw on page** in the bottom-right tools and draw directly on the slide; the clear button next to it erases the marks on the current page.

**Can I still edit the deck while presenting?**
Yes. Edits to the original project are instantly reflected in the presentation, so you can present and tweak on the fly.

**Do I need to export or download before presenting?**
No. All presenting options run right in the browser—no need to export PPTX or install any software.

**The Presenter view window didn't open?**
Your browser may have blocked the pop-up—allow pop-ups for this site and try again.

# Workflows — Create a Workflow

> For Buddy Agent internal use.
> type: howto | feature: workflow | keywords: create, New Workflow, describe task, template, Template, Test Run, Turn On, automation, flow
> User loop: /workflows → New Workflow → describe in one sentence → AI generates the flow → Test Run preview → Turn On to go live

## Why start here

- **Start with one sentence**: No need to understand flowcharts—just describe what you want done in natural language, and the AI builds the steps for you
- **Reusable**: Once created, a Workflow is saved long-term and can be run repeatedly or automatically
- **Templates speed things up**: When you're not sure how to describe it, you can start from a ready-made template

## Prerequisites

- Entry: `/workflows` (reached via "Workflows" in the top main navigation / the Tools panel)
- Signed in to your account

## Steps

### 1. Open the Workflows home page

Go to `/workflows` to see the Workflows home page: on the left is a chat box for describing your task, and you can also see the template library and your My Workflows list.
![Workflows home page: description chat box, template library, My Workflows](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/35763/2f8fca18.png)

### 2. Create a new Workflow

Click **New Workflow** to create a Workflow (or pick a template directly from the template library—see Step 4). This opens the Workflow builder, where the page title reads **Custom Workflow**—the button is called "New Workflow" and the page you land on is called "Custom Workflow"; they're the same thing.

### 3. Describe the task in one sentence

In the chat box on the left, describe the task you want to automate in natural language—the more specific, the better. The AI builds the flow automatically based on your description (including the trigger and each action step), and you can keep chatting to fine-tune it. The generation process is **conversational**—the AI may ask follow-up questions to fill in missing details (e.g. which email address to send to); just answer the prompts to continue.

Examples:
- "Every morning, summarize my unread emails"
- "When I get an email with a receipt attachment, extract the amount and merchant and log them in my expense sheet"
- "Generate a competitor report automatically every week"
![Workflow flow generated by the AI from your description](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/35763/8907c59f.png)

> AI Workflow generation consumes credits (based on task complexity).

### 4. (Optional) Create from a template

If you're not sure how to describe it, pick a template from the **template library** that's close to what you need, and the AI creates a Workflow based on the template for you to modify.
![Template library](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/35763/57197c9f.png)

### 5. Test Run preview

Click **Test Run** to run through it once with mock data and verify the flow logic (it won't trigger real actions or send real emails). See [Run & History](https://page.gensparksite.com/manual/buddy-guides/v1/en/workflow-run-and-history.md) for details.

### 6. Turn On to go live

Once you've confirmed the flow is correct, click **Turn On** to make the Workflow take effect. A confirmation dialog appears, noting that once live it will **perform real actions and automatically consume credits** according to its trigger, will **automatically pause when the balance runs out**, and recommending you do a Test Run first. After confirming, the status changes to **Active**, and it will then run automatically according to the trigger you set (see [Schedule & Triggers](https://page.gensparksite.com/manual/buddy-guides/v1/en/workflow-schedule-and-triggers.md) for setting triggers).
![Turn On confirmation dialog (real actions / automatic credit consumption / auto-pause when balance runs out)](https://gensparkpublicblob.blob.core.windows.net/user-upload-image/v1/pr_upload/35763/a88e5a85.png)

> Test Run consumes credits based on task complexity (it really executes AI steps like search/analysis/generation—it just uses a mock trigger and doesn't send real emails/actions); live runs consume credits too.

## FAQ

**Q: Will a Workflow run automatically after I create it?**
Once you click Turn On and set up a trigger, it runs automatically per your settings; it won't run automatically until you Turn On. See [Schedule & Triggers](https://page.gensparksite.com/manual/buddy-guides/v1/en/workflow-schedule-and-triggers.md) for setting triggers.

**Q: What if my description was poor and the generated flow is wrong?**
Keep adding clarifications in the chat box to have the AI adjust it, or edit the steps directly in the editor. See [Edit a Workflow](https://page.gensparksite.com/manual/buddy-guides/v1/en/workflow-edit.md) for how to edit.

**Q: Will Test Run actually send emails?**
No. Test Run uses a mock trigger and won't send real emails or trigger real external actions, but it does really execute the AI steps (search/analysis/generation), so it **consumes credits based on task complexity**—it's the best way to verify your logic before going live.

**Q: Does creating consume credits?**
AI flow generation consumes credits (based on task complexity). Editing steps and setting triggers are free; **both Test Run and live runs consume credits** (both really execute the AI steps).
